AVILEZ BURGUER — FLUXO OFICIAL: Projeto Local -> GitHub -> Vercel
=================================================================

Repositório oficial (ÚNICA fonte de verdade):
  https://github.com/navicpublis/avilez-burguer
Deploy: Vercel conectado ao GitHub (deploy automático a cada push na branch principal).

Rotas do app:
  "/"            -> Landing Page completa (Hero, Cardápio, Categorias, Avaliações, Footer)
  "/pedido/ID"   -> Rastreamento do pedido (cliente)
  "/admin"       -> Painel administrativo (Pedidos, Produtos, Estoque)

--------------------------------------------------
1) CONFERIR LOCALMENTE (antes de subir)
--------------------------------------------------
  npm install
  npm run build      # gera dist/ — tem que terminar SEM erro
  npm run preview    # abre http://localhost:4173
Abra "/": tem que aparecer a Landing (O MELHOR DA COSTA VERDE).

--------------------------------------------------
2) PUBLICAR (GitHub -> Vercel)
--------------------------------------------------
  git add -A
  git commit -m "sua mensagem"
  git push            # a Vercel detecta o push e faz o deploy sozinho
A Vercel reconhece o Vite automaticamente:
  Build Command = npm run build   |   Output Directory = dist
O vercel.json (na raiz) já cuida do fallback de SPA (rewrites p/ index.html),
essencial p/ /admin e /pedido/:id funcionarem no acesso direto e no refresh.

--------------------------------------------------
3) SE ALGO PARECER ANTIGO
--------------------------------------------------
  - Confirme que deu git push na branch que a Vercel acompanha (main/master).
  - Vercel -> Deployments: veja se o último deploy é o seu commit.
  - Se preciso, "Redeploy" no painel da Vercel.
  - Cache do navegador: Ctrl+Shift+R.

Obs.: netlify.toml e public/_redirects são de um fluxo antigo (Netlify) e a Vercel
os ignora — foram mantidos apenas por segurança e não atrapalham.
